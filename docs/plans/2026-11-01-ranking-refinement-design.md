# 首页与分赛道榜单精简

按用户截图移除首页报名按钮、首页介绍句、三步流程条和所有装饰星号，保留照片主视觉及五个项目卡片。图标使用现有 Lucide SVG，避免微信将特殊字符渲染成表情。

排行榜保留五赛道，移除赛道规则说明条。每个赛道提供综合、个人、团队三个页签，默认综合榜。综合榜将个人原始成绩与团队同赛道人均成绩一起降序排列，并列沿用竞赛排名。行内标明个人或团队；团队成绩单位显示“/人”，仍以所有已报名队员为分母。首页预览、排行榜、投屏、战报 CSV 保持一致。

有已保存图片且已提交成绩的个人显示“图片打卡”；只有图片而未完成成绩显示“图片已传 · 待提交”；其他个人仍显示“已打卡 / 待打卡”。公开接口仅增加是否有图片的布尔值，图片与元数据继续由本人、管理员授权查看。战报冻结当时的成绩与标记，旧战报综合榜仅从已有快照推导。

验证覆盖综合排名与并列、同名 ID 类型区分、赛道隔离、团队分母、图片标记与权限、旧战报兼容及导出；浏览器检查 320/360/390/430/1280 宽度、全部赛道和三种榜单模式、首页精简及投屏。上线备份数据库与照片，保留用户数据和关闭时间限制设置。
